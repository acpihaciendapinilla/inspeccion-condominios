# Instrucciones para asistentes de IA

Antes de hacer cualquier cambio en este repositorio, lee [COMO-HACER-CAMBIOS.md](COMO-HACER-CAMBIOS.md).

- Para cambios de personas, cargos, condominios, logos, apartados o puntos: modifica **solo** `configuracion.json` (y agrega imágenes en `logos/` si hace falta). No toques ningún otro archivo.
- Cambia únicamente lo que se pidió, conserva los `id` existentes y deja `configuracion.json` como JSON válido.
- Muestra el antes y el después y espera confirmación antes de subir.
